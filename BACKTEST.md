lognormal completion-delay CDF. Player growth is power-law, launch-surge,
or saturating. Counts are generated by summing cohort completions, not
by running the forecasting model. Snapshots refresh every four or six
hours. Cutoffs are 24/36/48 hours; horizons are 4/12/24/72/108 hours.

## Real history splits

The shared p00/p01 history is deduplicated by using p01, the longer prefix.
Training prefixes have 2 through 7 reads; each predicts 1, 2, or 3 reads
ahead where available, for 15 overlapping splits. All target snapshots
in these splits are unchanged, and all targets precede the first refresh.
Loss: model 0.000000, persistence 0.018939, curve 0.018939.
This establishes correct unchanged-page handling, not refresh accuracy.

## Actual practice targets and final

Neither input includes its target truth, and there is no reference directory
in the distributed kit. Actual p00/p01 pinball losses cannot be computed
locally. No server submission has been made by this build. The final
checkpoint and target are in the future relative to this build.
No claimed final advantage is supported by those unavailable answers.

## Reproducibility

Run `python3 evaluate.py --kit /path/to/kit --calibrate`.
The full machine-readable report is written under ignored `artifacts/`.
This Markdown report is generated from that report; it contains no hidden truth.
Curve spread combines the published random-walk term and regression residual
standard error with n-2 degrees of freedom. The exact house implementation
is unavailable; comparisons are to this documented replica.
